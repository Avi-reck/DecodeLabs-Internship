# 📚 DecodeLabs Internship – StudyMate Project

A responsive student planner web application built as part of the **DecodeLabs Full Stack Development Internship – Project 1**.

StudyMate helps students manage study tasks, deadlines, priorities, and progress using a clean and mobile-friendly interface.

## 🌐 Live Demo

[Studymate](https://avi-reck.github.io/DecodeLabs-Internship/)

## 🚀 Features

- Add study tasks
- Set subject and deadline
- Set task priority: High, Medium, Low
- Mark tasks as completed
- Delete tasks
- Search tasks by name or subject
- Filter tasks by All, Pending, and Completed
- Progress bar with task statistics
- Dark mode / light mode
- Responsive mobile-first layout
- LocalStorage support

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript ES6
- LocalStorage API

## 📱 Responsive Design

This project follows a **mobile-first design approach** and works on:

- Mobile phones
- Tablets
- Laptops
- Desktop screens

## 🎯 Internship Project Objective

The objective of this project is to build a responsive frontend interface using core web technologies without using any frontend framework.

This project focuses on:

- Semantic HTML
- CSS Flexbox
- CSS Grid
- Responsive design
- JavaScript DOM manipulation
- Form handling
- LocalStorage
- Clean UI/UX
